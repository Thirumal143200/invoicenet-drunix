### Quick Start (Dev Environment)

#### 1. Backend Server (Port 5000):
```bash
cd backend
npm install
npm run dev
```

#### 2. Frontend Interface (Port 3000):
```bash
cd frontend
npm install
npm run dev
```

Visit **`http://localhost:3000`** in your browser.
